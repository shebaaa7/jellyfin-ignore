Per-library ignore patterns

Enter one glob per line, relative to the selected library's root.

For example, zz Home Movies/** on a parent library skips that folder and its contents. For nested dedicated libraries, the plugin gives the dedicated library a separate alias path so Jellyfin does not merge both scans into one physical tree. Pattern matching uses DotNet.Glob.

Required for overlapping library roots. On Save, the plugin creates NTFS junctions in Jellyfin's plugin configuration directory and replaces only the dedicated library's configured path. Media is not moved or copied. Existing managed aliases are retained if this option is later disabled.
